# Ryazan City Bot

Telegram-бот для Рязани:

- `/start` + 3 inline-кнопки;
- автоматический статус БПЛА;
- текущая погода;
- реальные пробки по 4 районам прямо в Telegram;
- опциональная автоматическая публикация нового статуса БПЛА в Telegram-канал.

## 1. Создать бота

В Telegram откройте `@BotFather`:

1. `/newbot`
2. задайте имя и username;
3. скопируйте токен.

## 2. TomTom API

Для пробок нужен API-ключ TomTom.

Создайте developer account TomTom и API key с доступом к Traffic API.
Ключ вставляется в `.env` как `TOMTOM_API_KEY`.

Бот использует:

- Search/Geocoding API — определяет координаты нескольких дорог;
- Traffic Flow Segment Data v4 — получает `currentSpeed` и `freeFlowSpeed`;
- районная загрузка рассчитывается по нескольким улицам, а не по одной точке.

## 3. Настройка

Скопируйте:

```bash
cp .env.example .env
```

Заполните `.env`:

```env
BOT_TOKEN=...
TOMTOM_API_KEY=...
CHANNEL_ID=@your_channel
```

`CHANNEL_ID` можно оставить пустым — тогда бот не публикует БПЛА в канал сам,
а только показывает состояние при нажатии кнопки.

Если нужна автопубликация, добавьте бота администратором Telegram-канала
и дайте право публиковать сообщения.

## 4. Установка

Python 3.11+:

```bash
pip install -r requirements.txt
python bot.py
```

## Что показывает раздел «Пробки»

Для каждого района бот запрашивает несколько дорожных сегментов:

- Советский
- Московский
- Октябрьский
- Железнодорожный

Пример:

```text
🚗 ДОРОЖНАЯ ОБСТАНОВКА — РЯЗАНЬ

🟢 Советский — свободно
   загрузка: 8% · скорость: 44 км/ч

🟡 Московский — небольшая загрузка
   загрузка: 26% · скорость: 36 км/ч

🔴 Октябрьский — сильные пробки
   загрузка: 61% · скорость: 18 км/ч
```

Расчёт — отношение текущей скорости к скорости свободного потока.
Данные кэшируются на 2 минуты, чтобы не расходовать API-лимит при каждом клике.

## БПЛА

Источник статуса: `https://t.me/Radar_Ryazan62` (`@Radar_Ryazan62`).

Статус меняется **только** по двум фразам:

```text
БЕСПИЛОТНАЯ ОПАСНОСТЬ в Рязанской области!
```

→ статус `danger`.

```text
Отбой БЕСПИЛОТНОЙ ОПАСНОСТИ в Рязанской области!
```

→ статус `clear`.

Регистр, лишние пробелы и финальный восклицательный знак не мешают распознаванию.
Все остальные сообщения канала не переключают статус.

Последний распознанный статус хранится в `uav_state.json`, поэтому он не исчезнет,
когда соответствующий пост уйдёт из публичного Telegram-превью.

Если `CHANNEL_ID` заполнен, бот раз в минуту проверяет канал и публикует в ваш
Telegram-канал новое состояние только при изменении `danger ↔ clear`.

## Официальный источник

Региональная опергруппа сообщала, что официальный канал
«Оповещение Рязанская область» в MAX создан региональным министерством
цифрового развития и предназначен в том числе для сообщений об обстановке по БПЛА.

Когда у этого источника будет стабильный публичный API/доступ для автоматизации,
в проекте достаточно заменить функцию `fetch_uav_state()`.
